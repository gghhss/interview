    # 跨域及解决方案

    出于浏览器同源策略限制，浏览器会拒绝跨域请求

    同源策略：请求时拥有相同的 协议 域名 端口，只要有一个不同就属于跨域

    解决方案：

    1. 前后端协商 jsonp

    原理就是通过 script 的 src 不受同源策略限制，可以跨域请求数据来实现

    缺点：

    只能使用 get 请求，不安全、不易维护

    后端返回：

    一个函数，这个函数是在前端定义的，后端会把值注入到这个函数的参数里面 express

    import express from "express";

const app = express();

app.get("/api.jsonp", (req, res) => {
  const { callback } = req.query;
  res.send(`${callback}("Hello, world!")`);
});

app.listen(3000, () => {
  console.log("Server is running on http://localhost:3000");
});

    html

    <!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Demo</title>
    <body>
        <script>
            // 1. jsonp
            // 原理就是通过 script 的 src 不受同源策略限制，可以跨域请求数据来实现
            // 缺点：只能使用get 请求，不安全、不易维护
            // 后端返回：一个函数，这个函数是在前端定义的，后端会把值注入到这个函数的参数里面
            const jsonp = (name) =>{
                let script = document.createElement('script'); // 创建一个 script 标签
                script.src = `http://localhost:3000/api.jsonp?callback=${name}`; // 设置 src 属性为跨域的 API 地址
                document.body.appendChild(script); // 将 script 标签添加到文档中，浏览器会自动发送请求
                return new Promise((resolve, reject) => {
                    window[name] = (data) => { // 定义一个全局函数，后端会调用这个函数并传入数据
                        resolve(data); // 成功时调用 resolve
                        document.body.removeChild(script); // 请求完成后移除 script 标签
                        delete window[name]; // 清理全局函数
                    };
                });
            }
            jsonp(`callback${Date.now()}`)
                .then(data => {
                    console.log('jsonp data:', data);
                })
                .catch(err => {
                    console.error('jsonp error:', err);
                });

        </script>
    </body>

</html>
